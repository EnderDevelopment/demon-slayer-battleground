# Demon Slayer Battleground

This project contains the scripts for a Demon Slayer battleground game in Roblox Studio. It includes scripts for managing the game state, player abilities, demon spawning, and user interface elements. The scripts are designed to be placed in specific folders within Roblox Studio and provide the necessary functionality to create a Demon Slayer-themed battleground game.

## Install

1. Open Roblox Studio.
2. Create a new place or open an existing one.
3. Create the necessary folders (`ServerScriptService` and `StarterPlayerScripts`).
4. Copy the scripts from the `src` folder and paste them into the corresponding folders in Roblox Studio.

## Use

1. Place the `GameManager.server.lua` script in the `ServerScriptService` folder.
2. Place the `PlayerAbilities.server.lua` script in the `ServerScriptService` folder.
3. Place the `DemonManager.server.lua` script in the `ServerScriptService` folder.
4. Place the `UIManager.client.lua` script in the `StarterPlayerScripts` folder.
5. Adjust the game settings and spawn locations as needed.
6. Test the game in Roblox Studio.
